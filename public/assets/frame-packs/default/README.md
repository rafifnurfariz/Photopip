# Default frame pack

A working example frame pack: the scanner discovers this folder and shows "Default" in the
Frame tool. Its artwork keeps the photo-slot areas transparent so the photos show through.

To make your own frame, copy `_starter/` (not this folder) to `public/assets/frame-packs/my-frame` and
follow the steps there.

See `README.md` for the full contract and the slot map.
