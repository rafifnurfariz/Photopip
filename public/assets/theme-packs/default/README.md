# Default theme pack

A working example theme pack: the scanner discovers this folder and shows "Default" in the
Theme tool. Its artwork keeps the photo-slot areas transparent so the photos show through.

To make your own theme, copy `_starter/` (not this folder) to `public/assets/theme-packs/my-theme` and
follow the steps there.

See `docs/THEMES.md` for the full contract and the slot map.
